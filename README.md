# Asia-Pacific Economic Analysis (2020–2025)

This repository contains a comprehensive analytical study of the economic dynamics in the Asia-Pacific region, focusing on growth, stability, and employment trends using IMF datasets.

## 📊 Project Overview
An analysis of GDP growth, inflation, and structural dependencies across major Asia-Pacific economies. This project utilizes advanced data engineering to transform raw IMF data into actionable insights for strategic decision-making.

## 🛠️ Technology Stack
- **SQL**: Data transformation, CTEs, and complex joins for multi-dimensional analysis.
- **Excel**: Financial modelling and preliminary data cleaning.
- **Tableau**: Visual storytelling and interactive dashboards.

## 📁 Key Components
- `SQL Script .sql`: The core analytical logic used for data processing.
- `Data Viz/`: Exported visualizations showcasing key economic indicators.
- `CSV Files for Data Viz/`: Cleaned and processed datasets ready for BI integration.
